Git commands.
git *clone* - ("To download the repository from github to local")
cd [File location] - (To change the working directory)
git *add* [file name] - (To prepare the changes or created file or changed to the local git file)
git commit -m " Here we need to add the Commit message"(To save the file into the local git file )
git push origin [branch name(which branch we need to commit)] - (To save into the github)
